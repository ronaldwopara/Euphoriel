# How this vault works

This is a PARA second brain with three extra buckets because that is how this job actually arrives.

- **PARA:** Projects, Areas, Resources, Archive, plus Inbox
- **Conversations:** the talking
- **Messages:** the incoming
- **Tasks:** the doing
- **Daily:** the timeline

A project has an outcome and an end. An area does not end; it has a standard. If you are unsure, use the folder test: committed project → ongoing area → topic you care about → archive or delete.
