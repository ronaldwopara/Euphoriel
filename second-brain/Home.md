## Where things go

| It is… | Put it in |
| --- | --- |
| A raw dump, not filed yet | [[Inbox]] |
| A chat with a person or an agent | `Conversations/` |
| Something someone sent you | `Messages/` |
| A thing to do | [[Tasks]] |
| Work with a deadline | `Projects/` |
| An ongoing responsibility | `Areas/` |
| Reference you may need again | `Resources/` |
| Finished or paused | `Archive/` |
| What happened today | `Daily/` |

New notes default to `Inbox/`. File them when you know what they are.

## How to capture fast

1. Quick dump → new note in [[Inbox]] (or paste into today's daily note).
2. If it is a thread, use the Conversation template and leave it in `Conversations/`.
3. If someone pinged you, use the Message template in `Messages/`.
4. If it creates work, add a checkbox on [[Tasks]] and link the source.
5. Once a week, empty [[Inbox]]. Ask: project, area, resource, or archive?
