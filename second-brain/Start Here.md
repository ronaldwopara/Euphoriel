# Start Here

Open this folder as an Obsidian vault: **Open folder as vault** → `Euphoriel/second-brain`.

You do not need community plugins. Core Templates and Daily notes are already pointed at the right folders. Accent is a muted green so it sits next to the Euphoriel work without looking like a second product.

## The rule

Capture first. File later. The inbox can be messy. [[Home]] should stay clean.

## Daily rhythm

1. Open today's daily note (`Daily notes: Open today's note`).
2. Park anything that came in: messages, asks, decisions.
3. Move real work onto [[Tasks]] or onto a project note.
4. At the end of the day, write what changed in 5 lines. Future-you (and anyone picking this up) should be able to resume from [[Home]] plus yesterday's daily note.

## Templates

Command palette → **Templates: Insert template**

- Conversation
- Message
- Task
- Meeting
- Project
- Area
- Daily (applied automatically to new daily notes)

## Graph

Projects, conversations, and tasks are color-grouped. If a note has no links, it is an orphan. Link it to a project or to [[Home]] so it stays in the picture.

## Weekly

Insert the Weekly Review template. Empty [[Inbox]], move finished work, and write next week's three checkboxes onto [[Tasks]].

## Handing this to someone else

Give them this folder. Tell them to start at [[Home]], then [[Tasks]], then the active project. That is the whole briefing. Cursor in the parent repo is already pointed at those notes.
